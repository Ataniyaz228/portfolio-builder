# Adsum Portfolio Builder

**Adsum Portfolio Builder** — это full-stack платформа для создания и управления персональным портфолио.  
Проект позволяет пользователю редактировать профиль, публиковать проекты, навыки, опыт, отзывы и получать публичную страницу с готовым дизайном.

## 🎯 Цель проекта

Создать удобный инструмент, с которым специалист (разработчик, дизайнер, фрилансер) может:
- быстро собрать профессиональное портфолио;
- управлять контентом через личный кабинет;
- показывать свои работы по публичной ссылке;
- отслеживать активность и отклики.

## 👥 Целевая аудитория

- начинающие и опытные разработчики;
- дизайнеры и digital-специалисты;
- фрилансеры и соискатели;
- студенты для учебных/карьерных презентаций.

## ⚙️ Основные возможности

### Личный кабинет (Dashboard)
- редактирование профиля и аватара;
- управление блоками:
  - Projects
  - Skills
  - Experience
  - Testimonials
- уведомления и сообщения;
- базовая аналитика просмотров профиля.

### Публичная страница пользователя
- доступ по индивидуальному URL;
- несколько визуальных шаблонов портфолио;
- адаптивный интерфейс для мобильных и десктопа.

### Работа с изображениями
- загрузка изображений через API;
- хранение изображений в **Cloudinary** (устойчиво для продакшена);
- исключение проблем с локальным `uploads` на serverless-хостингах.

## 🧱 Архитектура

Проект состоит из двух частей:

1. **adsum-web** — frontend (Next.js)
2. **adsum-api** — backend (NestJS)

### Схема взаимодействия
- Frontend отправляет запросы в REST API backend.
- Backend работает с PostgreSQL (Neon), а медиа-файлы хранит в Cloudinary.
- Авторизация реализована через JWT.

## 🛠️ Технологический стек

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- Zustand

### Backend
- NestJS
- TypeScript
- TypeORM
- PostgreSQL (Neon)
- JWT Auth
- Multer + Cloudinary

### Инфраструктура и деплой
- **Vercel** — frontend
- **Render** — backend
- **Neon** — база данных PostgreSQL
- **Cloudinary** — хранение изображений

## 🔐 Безопасность и практики

- JWT-аутентификация для защищённых маршрутов;
- проверка и ограничения при загрузке файлов (тип/размер);
- CORS-настройка для работы frontend ↔ backend в проде;
- секреты вынесены в environment variables.
